\section*{MIMIC-IV rare-disease diagnosis: per-ICD-category evaluation}
All 15 training runs (best checkpoint per run) plus a frontier baseline, evaluated on the 2452-case MIMIC-IV rare-disease test set (greedy, $\le$8192 tokens), scored with the verl reward pipeline. \textbf{Accuracy is the lenient LLM-judge disease match} (judge: gpt-5.3-chat\_2026-03-03): a prediction is correct if the judge rules the diagnosed disease matches the ground truth, even if the exact ICD-10 code or phrasing differs (strict exact-match is lower). Embedding similarity is cosine between the predicted and ground-truth diagnosis (Qwen3-VL-Embedding-2B). $^\dagger$ frontier baseline. Best per column in \textbf{bold}.
\\[4pt]
\footnotesize Categories: Neopl=neoplasms (n=695), Endo=endocrine/metabolic (494), Nerv=nervous system (388), Blood=blood/immune (223), Circ=circulatory (141), Infec=infectious (102), Diges=digestive (88), Other (321).
